# WriEng

**打开就开始学的英语主动回忆网站。** v0.3 使用极简赛博界面，把一个大单词和当前动作放在首屏：看词听音 → 隐藏答案 → 手写或键入 → 提交看反馈 → 下一词。到期复习自动加入队列，词库、设置、记录和来源放在次级抽屉中。

无需账号。学习进度保存在当前浏览器的 IndexedDB，可导出、导入并离线使用。

## 在本机运行

推荐 **Node.js 24 LTS，24.15 及以上**；亦支持 Node.js 26 及以上。在项目目录运行：

```powershell
npm ci --ignore-scripts
npm run build
npm run preview
```

打开 **http://127.0.0.1:4173/**，保持预览终端运行。安装并构建完成后，也可双击 `Start-WriEng.cmd`。更新源码后先重新运行 `npm run build`。

开发模式：`npm run dev`，地址为 http://127.0.0.1:5173/。开发模式不注册离线缓存；验证离线功能请使用生产构建与预览服务。普通运行不需要 Python、词典服务或 API 密钥。

## 怎样学习

1. 首次使用可先完成 10 题自适应拼写短测，也可选择稍后再测；已有进度直接恢复当前阶段。短测只提供练习起点建议，不估算精确总词汇量。新词展示词义、实际提供的情境和发音内容。
2. 点击「隐藏单词，开始回忆」，看意思找回英文，可切换手写或键入。
3. 先提交，再揭晓。键入比较本轮原始拼写；手写显示本轮笔迹，供自己对照判断。使用提示、提前看过答案或拼错的尝试，会作为需要再练记录。
4. 选择回忆感受后保存并进入下一词。**ts-fsrs 5.4.2 / FSRS-6** 根据实际记录安排复习，到期词自动混入；每日新词上限和学习范围可在「词库与设置」调整。

词库支持搜索、路线筛选和分页，可把指定词加入接下来的队列。当前练习只安排手选词库内的新词与到期复习；其他词库的历史仍保留，明确手选的下一词也可额外学习。没有到期词或可引入的新词时，页面显示完成状态和下次复习时间。

当前没有手写识别器或发音评分。手写结果来自自评，笔迹图片仅保留在本轮页面内存中；刷新后不会恢复图片。键入正确、写出字形、听辨和语境运用也不被当作同一种掌握证据。

## 词库的真实规模

当前共 **6,172 个学习词义**，分为两种内容层级：

| 层级 | 数量 | 实际提供的内容 |
| --- | ---: | --- |
| 教学选编 | 172 | AI 辅助原创草稿，含 344 对双语例句、搭配、幽默助记及 IPA／节奏／发声提示；待专业复核 |
| 来源底库 | 6,000 | WordNet 3.0 英文释义、同一 synset 的 Chinese Open Wordnet 中文译词、CMUdict 源音素和真实 wordfreq 通用频率 |

底库中 **3,259 个词头有 WordNet 原例句，合计 5,113 句英文；另 2,741 条没有例句**。来源没有的中文例句翻译、助记、搭配或教学说明保持缺失；源同义词单独标注。候选记录不计入学习总数，也不进入学习队列。

底库中文是来源译词，并非新编的完整中文释义。6,000 条都保留实际 CMU 北美英语 ARPABET 音素与变体，词典美式 IPA 未提供。原 172 条教学选编中的 `copay` 仍明确没有 CMU 条目。已修正一批同形异读选择，其余义项对应读音与来源译词仍有复核边界。

播放优先选择设备提供的 `en-US` 声音，支持正常及整词慢速播放；具体声音、离线可用性和同形词读法取决于系统。没有真人录音库、逐音素同步或自动纠音，也未接入 Google 发音服务。

**wordfreq 3.1.1 的数值是拼写层面的通用英语混合语料估计，不是考试频率、某个词义的频率或美国口语排名。** 教学选编路线属于项目选词；底库 IELTS、TOEFL、六级、GRE 标签来自社区词表参考，不是官方必考清单或当前大纲认证。考试频率保持未知。

## 进度、复习与离线

原 172 条的 ID 保持不变，旧学习记录继续兼容。旧版事件、初次失败、提示使用和原到期点会保留；需要迁移时先在 IndexedDB 中保存升级前快照。FSRS 参数和版本固定，90% 是默认调度目标，不是实测记忆率。详见 [调度与迁移](docs/SCHEDULER.md)。

首次联网完整打开后，等待页面显示「离线已就绪」。之后应用和已缓存词库可离线学习、保存进度并刷新恢复。设备语音是否能离线播放由本机声音决定。应用更新需明确确认，缓存更新不清除学习记录。详见 [离线与安装](docs/OFFLINE.md)。

在「词库与设置 → 设置」可导出 JSON 或导入合并备份。换设备、浏览器、端口或切换本机与公开站点前先导出；这些存储来源不会自动同步。清除浏览器数据会删除本地进度，当前没有云同步。

## GitHub Pages

该仓库的 Pages 已启用。**v0.3 的发布状态以实际 GitHub Actions 结果及外网访问验证为准**；本地构建成功不表示公开站点已更新。

[Pages 工作流](.github/workflows/pages.yml) 在 `main` 更新时安装锁定依赖、检查类型、运行单元／组件测试，使用 `VITE_BASE_PATH=/WriEng/` 构建，再发布静态产物。普通本机构建默认使用 `/`。

Windows 手动验证仓库子路径：

```powershell
$env:VITE_BASE_PATH = '/WriEng/'
npm run build
Remove-Item Env:VITE_BASE_PATH
npm run preview
```

此时打开 **http://127.0.0.1:4173/WriEng/**。若验证浏览器套件，将 `WRIENG_TEST_URL` 设为该完整地址。恢复本机根路径预览前，清除 `VITE_BASE_PATH` 并重新构建。

## 快捷键、音效与选词建议

桌面学习区按 D 略过、B 只读回看上一词；略过不算掌握，回看不重复计数。输入框、输入法组合输入、弹窗及修饰键下不会触发字母快捷键。回看时 D 返回当前练习，未提交的输入和笔迹保留。

设置中可静音、调整音效音量（默认 12%）或试听。短音只响应明确操作，不在载入时自动播放。水平短测可稍后做或重新测；推荐依据真实通用词频、测试起点与足够的后续独立拼写证据，到期复习优先，并遵守手选词库范围。可手动调低或调高新词层级。全部本地运行，没有外部 AI 服务、费用或新账号。

当前验收结果与重跑命令见 [学习工具测试报告](docs/TEST-REPORT-LEARNING-TOOLS.md)，手机书写能力见 [手机修复报告](docs/TEST-REPORT-MOBILE-FIXES.md)。
